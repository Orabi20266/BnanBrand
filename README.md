# Omar Boxs — منصة عرض وتسويق صناديق الكرتون

موقع تعريفي وتسويقي متكامل (عربي RTL) لعرض وتسويق صناديق الكرتون عالية الجودة،
بتصميم عصري ومتجاوب وتجربة تسوق سلسة وموثوقة.

## التشغيل

الموقع ملفات ثابتة فقط — لا يحتاج تثبيت أي حزم أو أدوات بناء.

```bash
# افتح index.html مباشرة في المتصفح
open index.html

# أو شغّل خادماً محلياً (مفيد لاختبار الروابط عبر ?cat=)
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## هيكل الملفات

```
OmarBoxs/
├── index.html          الصفحة الرئيسية
├── products.html       صفحة المنتجات (بحث + تصفية + ترتيب)
├── about.html          عن الشركة
├── contact.html        التواصل ونموذج طلب عرض السعر
└── assets/
    ├── css/style.css   جميع التنسيقات (RTL، متجاوب، طباعة)
    └── js/
        ├── data.js     ← تعديل المنتجات والأسعار从这里
        ├── icons.js    أيقونات SVG + رسم توضيحي للصناديق
        └── main.js     السلة، التصفية، النوافذ، التحقق من النماذج
```

## الصفحات

| الصفحة | المحتوى |
|---|---|
| `index.html` | الواجهة الرئيسية، الميزات الست، التصنيفات، منتجات مميزة، خطوات العمل، آراء العملاء، الأسئلة الشائعة |
| `products.html` | 8 منتجات، 6 تصنيفات، بحث فوري، ترتيب بالسعر/التقييم/الاسم، جدول المقاسات |
| `about.html` | القصة، الرؤية والقيم، الالتزامات، الأرقام |
| `contact.html` | قنوات التواصل، نموذج بطلب عرض سعر مع تحقق كامل، أسئلة شائعة |

## تعديل المحتوى

كل النصوص والأسعار في مكان واحد: `assets/js/data.js`

- `CATEGORIES` — التصنيفات
- `PRODUCTS` — المنتجات (الاسم، السعر، المقاس، الخامة، الوصف، المميزات، ألوان الرسم)
- `TESTIMONIALS` — آراء العملاء
- `FAQS` — الأسئلة الشائعة
- `CONTACT` — الهاتف، الواتساب، البريد، العنوان، ساعات العمل

产品价格 `0` تعني «حسب الطلب» (يعرض زر طلب عرض سعر بدل زر السلة).

نصوص الأقسام الثابتة داخل كل صفحة في وسم `<script>` أسفل الملف.

## المزايا التقنية

- تصميم عربي RTL بالكامل بدون أي مكتبات خارجية
- متجاوب: 4 أعمدة على الشاشات الكبيرة ← عمود واحد على الجوال
- سلة مشتريات جانبية محفوظة في `localStorage`
- بحث وتصفية فورية بدون إعادة تحميل، مع مزامنة الرابط `?cat=`
- نموذج اتصال مع تحقق كامل ويفتح محادثة واتساب بالتفاصيل
- أرقام متحركة، كشف تدريجي عند التمرير، أسئلة شائعة بـ `<details>`
- نتائج اختبار Lighthouse: إمكانية وصول 100، أفضل الممارسات 100، SEO 100
- لا يتصل بأي خادم؛ كل البيانات محلية وجاهزة للربط بـ API لاحقاً

## ملاحظات للنشر

قبل رفع الموقع على نطاق حقيقي:

1. استبدل بيانات التواصل في `CONTACT` بأرقامك الحقيقية.
2. استبدل الأرقام الإحصائية (4200 عميل، 10 سنوات) بأرقامك الفعلية.
3. أضف صور منتجاتك الحقيقية بدل الرسوم التوضيحية — استبدل `BOX_ART(...)` بـ `<img src="...">` في `productCard()`.
4. فعّل HTTPS، وأضف `robots.txt` و `sitemap.xml`، وسجّل الموقع في Google Search Console.
